% ============================ 1. INTRODUCCIÓN ===============================
\section{Qué es el sistema}

Aplicación web desarrollada con \textbf{Django 6} y \textbf{PostgreSQL/Supabase}
para administrar:

\begin{itemize}[leftmargin=1.4em]
  \item Clubes afiliados y sus equipos.
  \item Deportistas (fichajes) y categorías.
  \item Campeonatos, fixture y partidos.
  \item Árbitros y designaciones.
  \item Tesorería y pagos.
  \item Usuarios, roles, auditoría y accesos.
  \item Portal público con clubes, canchas, resultados y próximos partidos.
\end{itemize}

La interfaz usa plantillas Django, Tailwind CSS compilado y JavaScript sin
frameworks. \textbf{No requiere Node.js} para funcionar.

% ============================ 3. INSTALACIÓN ================================
\section{Instalación paso a paso (Windows)}

\subsection{Instalar Git}

\begin{enumerate}[leftmargin=1.4em]
  \item Descargue Git desde \url{https://git-scm.com/download/win}.
  \item Ejecute el instalador con las opciones por defecto.
  \item Abra PowerShell y verifique:
\end{enumerate}

\begin{lstlisting}
git --version
\end{lstlisting}

Debe mostrar algo como \campo{git version 2.4x}.

\subsection{Instalar Python}

\begin{enumerate}[leftmargin=1.4em]
  \item Descargue Python 3.13 desde
        \url{https://www.python.org/downloads/windows/}.
  \item Marque \textbf{Add python.exe to PATH} durante la instalación.
  \item Verifique:
\end{enumerate}

\begin{lstlisting}
python --version
py --version
\end{lstlisting}

Debe mostrar \campo{Python 3.13.x} o superior. Si \campo{python} no se reconoce,
cierre y reabra PowerShell; si persiste, reinstale marcando la opción del PATH.

\subsection{Instalar VS Code (opcional)}

\begin{enumerate}[leftmargin=1.4em]
  \item Descargue \url{https://code.visualstudio.com/}.
  \item Instale la extensión \textbf{Python} de Microsoft.
  \item Abra la carpeta del proyecto con \textbf{Archivo $\rightarrow$ Abrir carpeta}.
  \item Seleccione el intérprete: \campo{Ctrl + Shift + P} $\rightarrow$
        \textbf{Python: Select Interpreter} $\rightarrow$
        \path|.\.venv\Scripts\python.exe|.
\end{enumerate}

\subsection{Base de datos}

\subsubsection{Opción A --- Supabase (recomendada, sin instalar nada)}

\begin{enumerate}[leftmargin=1.4em]
  \item Cree una cuenta en \url{https://supabase.com}.
  \item Cree un proyecto y guarde la contraseña de la base.
  \item En \textbf{Connect} (o \textbf{Project Settings $\rightarrow$ Database})
        copie la cadena \textbf{Session pooler} (puerto 5432).
  \item Reemplace \campo{[YOUR-PASSWORD]} por la contraseña real y asegúrese de
        que la cadena termine en\\
        \campo{?sslmode=require}.
\end{enumerate}

\begin{lstlisting}
postgresql://postgres.abcdefgh:MI_CLAVE@aws-1-us-east-1.pooler.supabase.com:5432/postgres?sslmode=require
\end{lstlisting}

Si el servicio web está en Render (Ohio), conviene que Supabase esté en una
región cercana (por ejemplo \campo{us-east-1}) para reducir la latencia.

\subsubsection{Opción B --- PostgreSQL local}

\begin{enumerate}[leftmargin=1.4em]
  \item Descargue PostgreSQL 16/17 desde
        \url{https://www.postgresql.org/download/windows/}.
  \item Anote usuario, contraseña y puerto (5432).
  \item Cree una base de datos, por ejemplo \campo{afo}.
\end{enumerate}

\begin{lstlisting}
postgresql://postgres:MI_CLAVE@localhost:5432/afo
\end{lstlisting}

\subsubsection{Opción C --- SQLite (solo pruebas locales)}

No requiere instalar nada. En \campo{.env}:

\begin{lstlisting}
DATABASE_URL=sqlite:///db.sqlite3
\end{lstlisting}

Sirve para probar el sistema, pero no se recomienda para producción.

\section{Crear el entorno virtual e instalar dependencias}

\begin{lstlisting}
# Crear el entorno (una sola vez)
py -3.13 -m venv .venv

# Permitir scripts locales en PowerShell (una sola vez)
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

# Activar el entorno
.\.venv\Scripts\Activate.ps1

# Actualizar pip e instalar dependencias
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
\end{lstlisting}

Si la activación falla, use el Python del entorno directamente:

\begin{lstlisting}
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
\end{lstlisting}

Verifique Django:

\begin{lstlisting}
python -c "import django; print(django.get_version())"
\end{lstlisting}

Debe mostrar \campo{6.1.x}.

% ============================ 11. USO =======================================
\section{Uso del sistema}

\subsection{Iniciar sesión}

Ingrese con el usuario y la contraseña del archivo de credenciales. El rol se
deduce automáticamente de la cuenta; no se elige en el formulario.

\subsection{Roles y permisos}

\begin{tabularx}{\textwidth}{@{}l X@{}}
\toprule
\textbf{Rol} & \textbf{Puede hacer}\\
\midrule
Administrador & Todo: clubes, equipos, deportistas, campeonatos, árbitros,
pagos, usuarios y auditoría.\\
Dirigente & Equipos, deportistas e inscripciones; consulta general.\\
Árbitro & Partidos y designaciones arbitrales; consulta general.\\
Tesorero & Tesorería y pagos; consulta general.\\
\bottomrule
\end{tabularx}

Los módulos restringidos (Usuarios, Auditoría, Tesorería) muestran ``Sin
permiso'' para los roles que no corresponden.

\subsection{Módulos principales}

\begin{xltabular}{\textwidth}{@{}l l X@{}}
\toprule
\textbf{Módulo} & \textbf{Ruta} & \textbf{Para qué}\\
\midrule
\endhead
Panel General & \campo{/panel-general/} & Resumen operativo y accesos rápidos.\\
Clubes & \campo{/clubes/} & Padrón de clubes afiliados.\\
Equipos & \campo{/equipos/} & Equipos por club, categoría y división.\\
Deportistas & \campo{/deportistas/} & Fichajes y datos de jugadores.\\
Categorías & \campo{/categorias/} & Primera A/B, Sub 15, Sub 19, etc.\\
Campeonatos & \campo{/campeonatos/} & Torneos y fixture.\\
Partidos & \campo{/partidos/} & Programación y resultados.\\
Árbitros & \campo{/arbitros/} & Registro de árbitros.\\
Asignaciones & \campo{/asignaciones/} & Ternas arbitrales.\\
Sanciones & \campo{/sanciones/} & Amonestaciones, suspensiones y multas.\\
Tesorería & \campo{/tesoreria/} & Pagos e ingresos.\\
Reportes & \campo{/reportes/} & Exportaciones PDF/Excel.\\
Usuarios & \campo{/usuarios/} & Cuentas y roles.\\
Auditoría & \campo{/auditoria/} & Historial de operaciones.\\
Accesos & \campo{/accesos/} & Inicios de sesión y bloqueos.\\
\bottomrule
\end{xltabular}

\subsection{Tareas frecuentes}

\begin{description}[leftmargin=0pt,style=nextline]
  \item[Crear un club.] Clubes $\rightarrow$ \textbf{Nuevo club}. Complete solo
        datos oficiales; no invente NIT, personería ni representantes.
  \item[Crear un equipo.] Equipos $\rightarrow$ \textbf{Nuevo equipo}. Seleccione
        club, categoría, división y temporada.
  \item[Registrar un jugador.] Deportistas $\rightarrow$ \textbf{Nuevo fichaje}.
        La CI debe ser única y con formato boliviano (por ejemplo
        \campo{12345678-OR}).
  \item[Crear un campeonato.] Campeonatos $\rightarrow$
        \textbf{Nuevo campeonato}. Luego programe partidos desde el fixture o
        desde \textbf{Partidos $\rightarrow$ Programar partido}.
  \item[Registrar un pago.] Tesorería $\rightarrow$ \textbf{Registrar pago}
        (solo Administrador y Tesorero).
\end{description}

% ============================ 12. MANTENIMIENTO =============================
\section{Pruebas y mantenimiento}

\subsection{Pruebas automáticas}

\begin{lstlisting}
python manage.py test
\end{lstlisting}

Usa una base SQLite en memoria: \textbf{no toca} la base real de Supabase.
Todas las pruebas deben pasar.

\subsection{Archivos estáticos}

En desarrollo Django los sirve solo. Para producción:

\begin{lstlisting}
python manage.py collectstatic --noinput
\end{lstlisting}

\subsection{Estilos (Tailwind)}

El CSS ya está compilado en \campo{static/css/tailwind.css}; no hace falta Node
para ejecutar el sistema.

Si modifica clases de Tailwind en plantillas, JavaScript o Python:

\begin{lstlisting}
powershell -ExecutionPolicy Bypass -File scripts\build_tailwind.ps1
python manage.py collectstatic --noinput
\end{lstlisting}

El script descarga la herramienta oficial la primera vez (requiere internet).

\subsection{Respaldos}

\begin{lstlisting}
# Crear respaldo
python manage.py backup_bd --etiqueta manual

# Verificar que el respaldo se puede restaurar
python manage.py verificar_respaldo --restaurar
\end{lstlisting}

Los respaldos se guardan en \campo{backups/} (ignorada por Git). Más detalles en
\campo{docs/SEGURIDAD.md}.

% ============================ 13. RENDER ====================================
\section{Publicar en Render (opcional)}

\begin{enumerate}[leftmargin=1.4em]
  \item Cree una cuenta en \url{https://render.com}.
  \item \textbf{New $\rightarrow$ Web Service $\rightarrow$ Public Git Repository}
        y pegue la URL del repositorio.
  \item Configure:
\end{enumerate}

\begin{tabularx}{\textwidth}{@{}l X@{}}
\toprule
\textbf{Campo} & \textbf{Valor}\\
\midrule
Nombre & \campo{afo-oruro}\\
Rama & \campo{main}\\
Runtime & Python 3\\
Plan & Free\\
Build Command & \campo{pip install -r requirements.txt \&\& python manage.py collectstatic --noinput \&\& python manage.py migrate}\\
Start Command & \campo{gunicorn sistema\_deportes.wsgi:application --bind 0.0.0.0:\$PORT --worker-class gthread --workers 1 --threads 4 --timeout 120}\\
Health Check Path & \campo{/health/}\\
\bottomrule
\end{tabularx}

\begin{enumerate}[leftmargin=1.4em,start=4]
  \item Agregue las variables de entorno:
\end{enumerate}

\begin{lstlisting}
SECRET_KEY=<clave-generada>
DEBUG=0
ALLOWED_HOSTS=.onrender.com
CSRF_TRUSTED_ORIGINS=https://*.onrender.com
DATABASE_URL=<cadena-de-supabase>
PYTHON_VERSION=3.13.7
AFO_TRUST_X_FORWARDED_FOR=1
\end{lstlisting}

\begin{enumerate}[leftmargin=1.4em,start=5]
  \item Cree el servicio y espere el despliegue.
  \item Verifique \campo{/}, \campo{/login/} y \campo{/health/}.
\end{enumerate}

\textbf{Notas:}
\begin{itemize}[leftmargin=1.4em]
  \item Con \textbf{Public Git Repository}, Render no despliega automáticamente:
        cada cambio requiere \textbf{Manual Deploy $\rightarrow$ Deploy latest commit}.
  \item El plan Free suspende el servicio tras $\sim$15 minutos sin tráfico; la
        primera visita puede tardar hasta 50 segundos.
  \item Los archivos subidos a \campo{media/} no son persistentes; use Supabase
        Storage o S3.
  \item El repositorio incluye una GitHub Action que consulta \campo{/health/}
        cada 10 minutos para mantener despierta la instancia.
\end{itemize}

% ============================ 14. PROBLEMAS =================================
\section{Solución de problemas}

\begin{xltabular}{\textwidth}{@{}>{\raggedright\arraybackslash}p{0.26\textwidth}
                                >{\raggedright\arraybackslash}p{0.26\textwidth}
                                X@{}}
\toprule
\textbf{Síntoma} & \textbf{Causa probable} & \textbf{Solución}\\
\midrule
\endhead
\campo{python} no se reconoce & Python no está en el PATH & Reinstalar marcando
``Add to PATH'' y reabrir PowerShell.\\
\campo{Activate.ps1} bloqueado & Política de ejecución & Ejecutar
\campo{Set-ExecutionPolicy -Scope CurrentUser RemoteSigned}.\\
\campo{No module named django} & Entorno no activado & Activar \campo{.venv} o
usar \path|.\.venv\Scripts\python.exe|.\\
\campo{DisallowedHost} & Dominio no permitido & Agregarlo a
\campo{ALLOWED\_HOSTS}.\\
Error CSRF en producción & Origen no confiable & Configurar
\campo{CSRF\_TRUSTED\_ORIGINS}.\\
No conecta a la base & Cadena incorrecta o proyecto pausado & Revisar
\campo{DATABASE\_URL}, \campo{sslmode=require} y Supabase.\\
Estáticos 404 en producción & Falta \campo{collectstatic} & Ejecutarlo en el
build.\\
Estilos viejos o incompletos & CSS sin recompilar & Ejecutar
\campo{scripts\textbackslash build\_tailwind.ps1} y \campo{collectstatic}.\\
Puerto ocupado & Otro servidor en 8000 & \campo{runserver 8001}.\\
Primera visita lenta & Plan Free dormido & Esperar o monitorear
\campo{/health/}.\\
Migración falla & Versión de Python incompatible & Usar Python 3.12+
(recomendado 3.13).\\
\bottomrule
\end{xltabular}

% ============================ 15. SEGURIDAD =================================
\section{Seguridad}

\begin{itemize}[leftmargin=1.4em]
  \item No subir \campo{.env}, \campo{backups/}, \campo{media/} ni archivos de
        credenciales al repositorio.
  \item En producción: \campo{DEBUG=0}, \campo{ALLOWED\_HOSTS} y
        \campo{CSRF\_TRUSTED\_ORIGINS} correctos.
  \item Usar contraseñas largas y únicas; cambiarlas después del primer ingreso.
  \item Guardar \campo{AFO-credenciales.txt} en un gestor de contraseñas y
        eliminarlo del disco.
  \item Revisar periódicamente \campo{/accesos/} y \campo{/auditoria/}.
  \item Mantener respaldos verificados y fuera del equipo principal.
\end{itemize}
